# Ольга Гончаренко — ленди безкоштовного уроку

> **Нове:** ленди безкоштовної лекції «Фінансовий порядок» — у папці [`finance/`](finance/README.md) (6 готових сайтів `finance/dist-*`).

Мобільні ленди (верстались тільки під телефон) для уроку
«Інструкція збільшення прибутку х2–3 за рік для будь-якого сервісного бізнесу».
Усі кнопки відкривають попап із віджетом SmartSender (точка входу у воронку, звʼязана з CRM).
Віджет: `WIDGET_ID` / `WIDGET_DOMAIN` у `src/content/landing.ts`, попап — `src/components/WidgetModal.tsx`.

| Варіант | Живий приклад | Готова збірка | Команда збірки |
|---|---|---|---|
| Короткий | https://olga-lesson-short.vercel.app | `dist-short/` | `npm run build:short` |
| Інший дизайн, світлий | https://olga-lesson-v3.vercel.app | `dist-v3/` | `npm run build:v3` |
| Інший дизайн, темний | https://olga-lesson-v3-dark.vercel.app | `dist-v3dark/` | `npm run build:v3dark` |

Папки `dist-*` — уже зібрані статичні сайти (HTML + JS + CSS + картинки + відео).
Їх можна просто залити на будь-який хостинг або в піддиректорію сайту — шляхи відносні.

## Стек
React 18 + Vite 5 + TypeScript, без бекенду. Варіант обирається змінною `VITE_VARIANT` під час збірки.

## Запуск
```
npm install
npm run dev:short    # http://localhost:5191
npm run dev:v3       # http://localhost:5192
npm run dev:v3dark   # http://localhost:5193
```

## Віджет і аналітика джерела
Кнопки лишаються звичайними `<a href={BOT_URL}>` — `WidgetModal` перехоплює клік і відкриває попап
із віджетом. Якщо JS не відпрацює (або клік із Ctrl / Cmd), посилання веде в бот, як і раніше.

Віджет (iframe зі своїм SPA) вантажиться повільно, тому попап не чекає на клік: зʼєднання
прогрівається через `preconnect` одразу, а скрипт підвантажується на першому простої сторінки.
Прихований попап лишається в DOM — тому клік відкриває вже готову форму, а не починає завантаження.
Запасне посилання в попапі веде на сторінку того самого віджета: форма з телефоном там та сама.

У віджет передається `ssContext.scope`, звідки SmartSender забирає мітки в CRM:

| Поле | Значення |
|---|---|
| `lp` | з якого ленда клік: `short`, `v3`, `v3dark` |
| `utm_*`, `fbclid`, `gclid`, `ttclid` | як є з адреси сторінки (`src/lib/utm.ts`) |
| `utm_source` | якщо в адресі його не було — підставляється назва ленда |

Пікселі не підключені. Додавати в `index.html` (спільний для всіх варіантів).

`App.tsx` і `dist/` — повна версія (варіант 1, https://olga-lesson.vercel.app), у цю інтеграцію не входить.
